# המסגרת שלי

אפליקציית Expo / React Native / TypeScript בעברית וב־RTL, לניהול אנשים, מצבה, שמירות, כיתת כוננות ומשימות. נתוני הפתיחה בקוד הם דוגמאות.

## הפעלה

נדרשים Node.js ו־pnpm. התלויות מנוהלות עם pnpm וקובץ הנעילה שלו:

```sh
pnpm install --frozen-lockfile
pnpm run web
```

לתצוגת Safari באייפון דרך מנהרה זמנית:

```sh
pnpm exec expo start --web --tunnel --port 8090
```

Expo עשוי לבקש להתקין את רכיב המנהרה. פותחים ב־Safari את קישור ה־HTTPS שמתקבל עם `?platform=web`. קוד QR מסוג `exp://` מיועד ל־Expo Go. המנהרה זמנית ותלויה בשרת ובחיבור האינטרנט של המחשב. ב־Windows אפשר להשתמש ב־`run-iphone-preview-tunnel.bat`.

## בדיקה ובנייה

```sh
pnpm run typecheck
pnpm run build:web
```

האתר המוכן נוצר בתיקיית `dist`, שאינה נשמרת ב־Git. מסגרת האייפון מגיעה מ־`public/iphone-preview.html`.

## מה קיים

- מסך בית שחור־סגול עם הרים, ברכה לפי שעה, מצבה ושמירות.
- אנשים עם תיק אישי, קבוצה אחת (בודדים, נשואים או השאר), סימון מפקדים, חיפוש ובחירה למחיקה מרוכזת.
- שדות אישיים לרפואי, ת״ש, כושר, משמעתי וערכי.
- יום הולדת בתיק האישי, ואפשרות לבת זוג עם שם, יום הולדת ותאריך תחילת הקשר. משך הקשר מחושב אוטומטית; השדות נכללים בשמירה ובגיבוי JSON. התאריכים מוצגים כ־יום/חודש/שנה.
- בחירת תאריכים בגלגלות יום, חודש ושנה, עם התאמה לחודשים קצרים ושנים מעוברות. תאריכים אישיים מוגבלים לעבר; משימות מאפשרות גם תאריך עתידי. לחיצה על תאריך משימה קיימת פותחת עריכה.
- גלגלות תאריך ושעה מתיישרות למרכז ערך שלם בסיום הגלילה, עם הדגשה עדינה של הבחירה. רטט קצר מופעל רק בדפדפנים שתומכים ב־Vibration API; Safari באייפון אינו תומך בממשק זה.
- עריכת תמונת אדם במסגרת עם זום, גרירה וצביטה. התמונה נשמרת כעותק מוקטן וקבוע במכשיר; המסגור נשמר בנפרד כדי לאפשר עריכה חוזרת. שדות הכתיבה מוגדרים לעברית ולימין. זום הדפדפן חסום לפי העדפת המשתמש, והזום הפנימי באנשים ובתמונה נשאר זמין.
- תמונות האנשים מוצגות במלבן פספורט אנכי ביחס 35:45. לחיצה על התמונה בכרטיס האישי פותחת עריכה ושומרת אותה ישירות באישור. בעריכת פרטים האישור מעדכן את הטיוטה, ואז שומרים את כל הפרטים. תמונה ישנה שנשמרה בקישור זמני וכבר אינה זמינה מציגה אפשרות לבחירה מחדש; שאר הרשומה נשמרת.
- בפתיחה נעשה ניסיון להמיר קישורי תמונה זמניים מגרסאות ישנות לעותק קבוע, אם הם עדיין פעילים. קישור שכבר פג אינו נמחק מהנתונים ומוצגת אפשרות לבחירה מחדש; אין אפשרות לשחזר ממנו את קובץ התמונה שכבר אינו זמין.
- מצבה עם נוכחות, סיבות ובסיסים ניתנים לעריכה ולעדכון מרוכז.
- טבלת שמירות וטבלת כפכ״פ עם ארבעה לוחמים ומפקד לכל טווח שעות. כותרות הלוחמים ניתנות לעריכה.
- משימות ותפריט שועל. רפואה, ת״ש, כושר, חינוך וכשירות הם כרגע מסכי תכנון בלבד.

## נתונים

גרסת הדפדפן שומרת ב־localStorage באותו מכשיר, דפדפן וכתובת. תפריט השועל כולל גיבוי ושחזור JSON. מעבר למכשיר אחר או לכתובת מנהרה אחרת מצריך העברת גיבוי. אין כרגע משתמשים, שרת נתונים או סנכרון בין מכשירים. בגרסת התקנה מקורית טרם הוגדר אחסון קבוע.

## מבנה הקוד

- `App.tsx`: מסכים ופעולות.
- `theme.ts`: צבעים וריווח.
- `deviceStorage.ts`: שמירה, בדיקת גיבויים ושחזור.
- `peopleAndReadiness.ts`: כללי הקבוצות והכוננות.

## GitHub ואירוח

### פריסה קבועה לאייפון

המאגר: `https://github.com/cff8mvzw8t-del/my-app`. תהליך GitHub Actions בקובץ `.github/workflows/pages.yml` בונה ומפרסם את ענף `master` ל־GitHub Pages. יש לבחור פעם אחת במאגר **Settings → Pages → Source: GitHub Actions**. הכתובת הצפויה: `https://cff8mvzw8t-del.github.io/my-app/`.

ב־Safari פותחים את כתובת האפליקציה עצמה, בוחרים שיתוף ואז הוספה למסך הבית. אחרי ההורדה הראשונית מופיעה הודעה שהאפליקציה מוכנה לשימוש ללא אינטרנט. ניתן לפתוח מחדש ולערוך נתונים גם בלי המחשב ובלי חיבור. יש לבדוק זאת באייפון עצמו לפני שימוש יומיומי. מטמון הדפדפן עשוי להימחק; שימוש ללא אינטרנט אינו גיבוי.

עדכון חדש מוצג כהודעה ומופעל רק בבחירה מפורשת או לאחר סגירת החלונות הישנים. אין רענון אוטומטי בזמן עריכה. יש לסיים עריכה ולסגור חלונות נוספים לפני אישור עדכון.

להכנת אותה גרסה במחשב:

```powershell
$env:PAGES_BASE_PATH='/my-app'
pnpm run test:pwa
pnpm run build:web
```

לבנייה עבור שורש אתר מקומי משאירים את `PAGES_BASE_PATH` ריק. אין סיסמאות או מפתחות שירות בגרסה הנוכחית. מסד נתונים ושרת אינם נדרשים לפריסה הזו. העברת נתונים מכתובת ישנה נעשית באמצעות גיבוי ושחזור JSON.
