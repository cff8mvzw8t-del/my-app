# המסגרת שלי

אפליקציית Expo / React Native / TypeScript בעברית וב־RTL, לניהול אנשים, מצבה, שמירות, כיתת כוננות ומשימות. נתוני הפתיחה בקוד הם דוגמאות.

## הפעלה

נדרשים Node.js ו־pnpm. התלויות מנוהלות עם pnpm וקובץ הנעילה שלו:

```sh
pnpm install --frozen-lockfile
pnpm run web
```

לתצוגת Safari באייפון דרך מנהרה זמנית:

```sh
pnpm exec expo start --web --tunnel --port 8090
```

Expo עשוי לבקש להתקין את רכיב המנהרה. פותחים ב־Safari את קישור ה־HTTPS שמתקבל עם `?platform=web`. קוד QR מסוג `exp://` מיועד ל־Expo Go. המנהרה זמנית ותלויה בשרת ובחיבור האינטרנט של המחשב. ב־Windows אפשר להשתמש ב־`run-iphone-preview-tunnel.bat`.

## בדיקה ובנייה

```sh
pnpm run typecheck
pnpm run build:web
```

האתר המוכן נוצר בתיקיית `dist`, שאינה נשמרת ב־Git. מסגרת האייפון מגיעה מ־`public/iphone-preview.html`.

## מה קיים

- מסך בית שחור־סגול עם הרים, ברכה לפי שעה, מצבה ושמירות.
- אנשים עם תיק אישי, קבוצה אחת (בודדים, נשואים או השאר), סימון מפקדים, חיפוש ובחירה למחיקה מרוכזת.
- שדות אישיים לרפואי, ת״ש, כושר, משמעתי וערכי.
- מצבה עם נוכחות, סיבות ובסיסים ניתנים לעריכה ולעדכון מרוכז.
- טבלת שמירות וטבלת כפכ״פ עם ארבעה לוחמים ומפקד לכל טווח שעות. כותרות הלוחמים ניתנות לעריכה.
- משימות ותפריט שועל. רפואה, ת״ש, כושר, חינוך וכשירות הם כרגע מסכי תכנון בלבד.

## נתונים

גרסת הדפדפן שומרת ב־localStorage באותו מכשיר, דפדפן וכתובת. תפריט השועל כולל גיבוי ושחזור JSON. מעבר למכשיר אחר או לכתובת מנהרה אחרת מצריך העברת גיבוי. אין כרגע משתמשים, שרת נתונים או סנכרון בין מכשירים. בגרסת התקנה מקורית טרם הוגדר אחסון קבוע.

## מבנה הקוד

- `App.tsx`: מסכים ופעולות.
- `theme.ts`: צבעים וריווח.
- `deviceStorage.ts`: שמירה, בדיקת גיבויים ושחזור.
- `peopleAndReadiness.ts`: כללי הקבוצות והכוננות.

## GitHub ואירוח

המאגר מיועד להיות פרטי. קובצי סביבה, מפתחות וגיבויים אישיים אינם מיועדים ל־Git. נתוני הדפדפן אינם חלק מקוד המאגר.

Railway הוא מועמד לאירוח ולמסד PostgreSQL בהמשך. כרגע האפליקציה מוציאה אתר לקוח בלבד: אירוח האתר לא מחבר אוטומטית את הנתונים למסד. לפני שימוש יומיומי נותר לסגור כתובת קבועה, כניסה והרשאות, אחסון וגיבויים. טרם בוצעה פריסה ל־Railway.
